# ROUND ONE — FINAL v6

This is the final consolidated PWA build.

Included:
- Personalized 6:00 AM–10:30 PM routine
- Water tracking with 3 L target
- Study and boxing targets
- Herb/diet checklist
- Custom tasks
- Daily reset
- Local persistence
- In-app reminder engine
- Notification permission flow
- Weekly dashboard and 7-day chart
- Streak tracking
- Mobile/iPhone navigation
- Offline-first PWA behavior

Important notification note:
A GitHub Pages PWA can request iPhone web-notification permission and display notifications when supported, but truly scheduled push notifications while the app is fully closed require a Web Push backend/service. This build does not pretend that browser timers are guaranteed background alarms. The notification UI is ready for that future backend if you ever choose to add one.
