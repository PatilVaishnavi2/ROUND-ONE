# ROUND ONE Build Checklist

- [ ] Install Node.js 20+
- [ ] Run `npm install`
- [ ] Run `npm run build`
- [ ] Run `npm run dev` and test the browser/PWA
- [ ] Run `npx cap add android`
- [ ] Run `npm run cap:sync`
- [ ] Open Android Studio and test notifications
- [ ] Test a real Android phone with the app minimized/locked
- [ ] Run `npm run electron` on Windows
- [ ] Test tray behavior
- [ ] Test a reminder while the window is hidden
- [ ] Run `npm run electron:dist` on Windows
- [ ] Test the installer on a clean Windows machine
- [ ] Add cloud sync before publishing to multiple devices
